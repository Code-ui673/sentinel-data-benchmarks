# Beta-Lactam ICU Dosing Cohort — free sample

> **This folder contains the technical documentation, the validation code and a free evaluation sample (400 patients, 5 dosing regimens) — not the full dataset.**  
> **Full dataset (400 patients, 5 regimens, 10 linked tables, full PK truth layer):** **[sentineldata.com.ua/dataset/betalactam-icu-dosing-cohort](https://sentineldata.com.ua/dataset/betalactam-icu-dosing-cohort)**

Four hundred synthetic adult ICU patients, each receiving five beta-lactam dosing regimens in parallel. Each patient's true pharmacokinetic trajectory — volume of distribution, clearance, free-drug concentration every 15 minutes across 72 hours — is generated by a two-compartment ODE model with Bayesian patient-specific parameters, then placed alongside the noisy clinical record (TDM samples, dose records, organ function labs) a real ICU would actually see. The question is whether a 24-hour bedside drug level, combined with patient characteristics and microbiology, is enough to predict pharmacodynamic failure before it materialises.

**DOI (Zenodo):** [10.5281/zenodo.24376814](https://doi.org/10.5281/zenodo.24376814)  
**Also archived:** [Kaggle (free sample)](https://www.kaggle.com/datasets/corot7b/betalactam-icu-dosing-cohort)

**Status: MODEL-GENERATED / HYPOTHETICAL.** Fully synthetic data from a two-compartment PK/PD model and a Bayesian TDM simulator. No real patient stands behind any row. It supports method development for therapeutic drug monitoring, beta-lactam dosing optimisation, and PK/PD prediction tasks; it is not clinical evidence and does not replace a real cohort study.

## What the data are good for

- **PK/PD failure prediction from bedside data.** The free-drug concentration trajectory is hidden; only the noisy TDM sample and dose records are observed. Can a 24-hour level predict whether the patient will reach the PK/PD target by hours 48–72? This is the benchmark task.
- **Bayesian TDM and dose-adjustment method evaluation.** `tdm_predictions.parquet` contains MAP estimates of Vd, clearance, AUC, and the predicted 48-hour free concentration produced by a Bayesian TDM engine — a ready-made comparator for any new estimation approach.
- **Comparative effectiveness of dosing regimens.** Five regimens span four drugs (meropenem, piperacillin-tazobactam) and three administration strategies (bolus, extended infusion, continuous infusion), all run on the same patient with the same random seed. The ground-truth PK metrics in `patients_truth.parquet` allow unconfounded comparison.
- **Teaching**, with the full PK truth layer (true Vd, true CL, true AUC, true 72-hour %fT>MIC) stored alongside the clinical record.

## Validation / benchmark

`validation/benchmark_script.py` is the exact script that produced the published benchmark numbers. It trains logistic regression and XGBoost with five-fold stratified cross-validation (split by patient), predicting whether the free beta-lactam concentration fails to exceed the MIC for 100 % of hours 48–72 under regimen A (label bolus dosing), from information available at the bedside.

**Three feature sets are compared:**

| Feature set | Description |
|---|---|
| `characteristics_plus_first_level` | Age, weight, organ function, flags, drug type, 24 h TDM level + derived TDM features |
| `characteristics_plus_microbiology` | Same characteristics + pathogen species and MIC, no TDM |
| `characteristics_plus_first_level_plus_microbiology` | All of the above |

**Published results (seed 20261119, 5-fold CV, 400 patients):**

| Feature set | Model | AUROC (mean ± SD) | AUPRC | Brier |
|---|---|---|---|---|
| characteristics + first level + microbiology | XGBoost | **0.970 ± 0.003** | 0.927 | 0.059 |
| characteristics + first level + microbiology | Logistic regression | 0.956 ± 0.002 | 0.897 | 0.069 |
| characteristics + microbiology (no TDM) | XGBoost | 0.893 ± 0.007 | 0.777 | 0.105 |
| characteristics + first level (no MIC) | XGBoost | 0.809 ± 0.005 | 0.639 | 0.136 |

The drop from 0.970 to 0.809 when MIC is withheld shows the value of the microbiological result. The XGBoost ceiling of 0.809 without MIC reproduces the published Wieringa 2023 benchmark (AUROC 0.79–0.80; doi:[10.3390/antibiotics12121674](https://doi.org/10.3390/antibiotics12121674)) on a comparable task, confirming the synthetic data captures realistic task difficulty.

**Usage:**

```bash
pip install -r validation/requirements.txt
python validation/benchmark_script.py sample/ output_results.parquet
```

The notebook in `notebook/validate_sample.ipynb` runs the same script and displays the results table.
