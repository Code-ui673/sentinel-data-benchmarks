# Code Sentinel Data — benchmarks & samples

Open technical documentation, free evaluation samples and reproducible validation code for [Code Sentinel Data](https://sentineldata.com.ua)'s synthetic clinical datasets.

Each dataset lives in its own folder: a free row-level sample, the exact validation/benchmark script used for the published metrics, and a notebook that re-runs it against the sample as a reproducibility smoke test.

**This repository does not contain full datasets.** Full datasets (thousands of subjects, full table sets, Zenodo DOIs) are sold at [sentineldata.com.ua](https://sentineldata.com.ua) under a commercial research license. Every dataset's full citation, DOI and known limitations are documented inside its own folder's README.

## Status

All data here is **synthetic** — generated from published disease/physiology models, not derived from real patient records. See each dataset's own README for its specific generation methodology, validation results and limitations.
